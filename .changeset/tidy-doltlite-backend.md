Add an experimental DoltLite backend and managed store with recorded history, native branch working copies merged through TypeGraph, and exact cosine/L2 vector search. The backend requires a patched DoltLite Node binding that preserves extended SQLite errors; the repository includes a pinned, checksum-verified source build and upstream patch. ANN indexing and browser/WASM support are not provided.
