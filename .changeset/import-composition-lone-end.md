`importGraph` and `importGraphStream` with `onConflict: "update"` no longer write the end of a composition attachment alone when the document attaches the part again with a row that is not applied. 0.75 refused such an end only when the document held exactly one row ending the attachment and exactly one re-attaching row refused while the document was classified. Other shapes still committed the end and left an optional part with no whole: a re-attaching row whose caller-assigned id names a stored edge (an ended edge of the same part, a deleted edge, which import skips without an error, or another part's edge), two refused re-attaching rows, a refused row whose id the document repeats, a repeated end, or a row ending an attachment the same document creates while the row moving the part on is refused when it is created.

Every part a row stops attaching, outside a pair applied as one move, that another row attaches again is now judged once by one verdict, whatever stage refuses its re-attaching rows. When none of them attaches the part, every row ending its attachment is refused with `INTERCHANGE_COMPOSITION_MOVE_INCOMPLETE`, naming those rows, and the part keeps its current whole. A refusal the classification already settles is applied before anything is written. One that only shows once a row is created or repeated rolls the edge writes back to a savepoint and runs them again with the end refused, as a failed move already does; a backend whose transaction offers no savepoint aborts such an import with `IMPORT_COMPOSITION_MOVE_REQUIRES_SAVEPOINT` instead of committing the lone end. A row restating the edge being ended, or a row whose window is already ended, does not count as attaching the part again, so a lone end the document states on purpose is still written. Required parts were already protected by `COMPOSITION_DETACH_REFUSED`; when the refusal is settled before anything is written, their end now reports `INTERCHANGE_COMPOSITION_MOVE_INCOMPLETE` like an optional part's. The outcome is the same at every `batchSize` and through `importGraphStream` for a document in one chunk.
